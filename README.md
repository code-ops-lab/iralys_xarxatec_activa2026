# JavaScript - Curso de Desarrollo Web

Repositorio de prácticas, ejercicios y entregables desarrollados durante mi formación en **Desarrollo Web**, utilizando **JavaScript** como lenguaje principal.

El propósito de este repositorio es documentar el proceso de aprendizaje mediante la resolución de ejercicios prácticos y la aplicación progresiva de los principales conceptos de programación y Programación Orientada a Objetos (POO).

---

## Tecnologías utilizadas

* JavaScript (ES6+)
* Node.js
* Git
* GitHub
* Visual Studio Code

---

## Objetivos de aprendizaje

* Comprender los fundamentos de JavaScript.
* Desarrollar la lógica de programación y la resolución de problemas.
* Aplicar la Programación Orientada a Objetos.
* Utilizar Git y GitHub como herramientas de control de versiones.
* Organizar el desarrollo mediante ramas temáticas para facilitar el seguimiento del aprendizaje.

---

## Estructura de ramas

Cada rama del repositorio está dedicada al estudio de un tema específico del curso.

| Rama                     | Contenido                                                                                                      |
| ------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `develop`                | Rama de integración y desarrollo general del proyecto.                                                         |
| `feat/fundamentos`       | Variables, constantes, tipos de datos, operadores y estructuras básicas de JavaScript.                         |
| `feat/funciones`         | Declaración de funciones, parámetros, valores de retorno, funciones flecha y reutilización de código.          |
| `feat/while`             | Bucles `while`, control de iteraciones y resolución de ejercicios repetitivos.                                 |
| `feat/arrays`            | Creación y manipulación de arrays, recorrido de elementos y métodos más utilizados.                            |
| `feat/clases`            | Introducción a las clases, objetos, constructores y principios básicos de la Programación Orientada a Objetos. |
| `feat/getSetter`         | Implementación de getters y setters, encapsulación y control de acceso a las propiedades de los objetos.       |
| `feat/herencia`          | Herencia entre clases, reutilización de código y relaciones entre clases padre e hijas.                        |
| `feat/segundoEntregable` | Ejercicios y actividades correspondientes al segundo entregable del curso.                                     |

## Metodología de trabajo

Para cada tema del curso se sigue el siguiente flujo de trabajo:

1. Creación de una rama específica para el tema.
2. Desarrollo de ejercicios prácticos y actividades propuestas.
3. Realización de commits descriptivos para registrar el progreso.
4. Integración del trabajo en la rama de desarrollo correspondiente.
5. Publicación en GitHub como evidencia del proceso de aprendizaje.
