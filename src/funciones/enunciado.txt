=========================================
EJERCICIO 1 (MEDIO-ALTO)
=========================================

Crear una función:

numerosUnicos()

Recibe un array de números.

Debe devolver un nuevo array sin elementos repetidos.

Ejemplo:

[5, 3, 8, 5, 2, 3, 8]

Resultado:

[5, 3, 8, 2]

Restricciones:

- No usar Set()
- No usar includes()
- No usar indexOf()
